# My Second App

A small React app that combines two simple demo features in one interface: a student registration form and a blog-style post feed.

## Features

- Add and remove students from a registration list
- Track a list of registered courses and names
- Create blog posts with a selected author name
- Like posts and delete posts you authored
- Switch between the two demos from the same app

## Tech Stack

- React
- Vite
- JavaScript
- CSS

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Open the local URL shown in the terminal to view the app in the browser.

## Production Build

To create a production build:

```bash
npm run build
```

## Linting

```bash
npm run lint
```

## Project Structure

- `src/App.jsx` — main app logic and UI
- `src/App.css` — styling for both demo sections
- `public/` — static assets

## Notes

This project is a frontend practice app built to demonstrate core React concepts such as state management, event handling, conditional rendering, and list rendering.
